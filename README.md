# QQ AI 功能插件 (qqAI)

## ✨ 功能
 - 自动回复
 - 指令回复
 - 分支对话
 - 进群验证
 - 退群通知
 - 私信反馈意见
 - 轻量的学习功能（非 AI，无需联网和 Token）
## 📦 安装方法

1. AstrBot WebUI 的「插件市场」中，选择「从 Git 仓库安装」，输入以下地址：
`https://github.com/HAGoStudio/astrbot_plugin_qqAI`
2. 重启 AstrBot
> 💡 首次启动时，插件会自动在 AstrBot 根目录下的`data/plugin_data/astrbot_plugin_qqAI/` 目录下创建所需的配置文件，无需手动配置

## 🚀 使用方法

配置文件位于 AstrBot 根目录下的`data/plugin_data/astrbot_plugin_qqAI`下

### zdhf.json —— @ 机器人触发（直接编辑）

| 名称 | 介绍 | 示例 |
|------|------|------|
| gjc  | 关键词 → 回复内容映射 | `{"检测的内容": "收到后的回复"}` |
| sfjt | 是否继续匹配下一条规则 | `true` / `false` |
| jtc  | 当 `sfjt` 为 `true` 时的子规则列表 | `[{"监听词1": "回复1"}, {"监听词2": "回复2"}]` |

**支持的变量**：`{{当前时间}}`

### zdhf.json —— 可视化编辑

在 AstrBot WebUI 中：`插件 → QQAI → 打开插件UI界面 → 规则编辑器`

| 名称 | 说明 | 示例 |
|------|------|------|
| 关键词 | 触发词 | `你好` |
| 回复内容 | 对应的回复 | `你好呀！` |
| 接着监听 | 勾选后继续匹配下一条 | `不勾选` |
| 添加选项 | 添加子规则（需勾选「接着监听」） | 监听 `选项1` 返回 `已选择选项1` |
| 删除该规则 | 删除本条规则 | - |
| 删除该项 | 删除子规则中的某一项 | - |
| 添加规则 | 新增一条规则 | - |
| 保存全部 | 保存所有规则 | - |
| 刷新 | 重新渲染规则列表 | - |

### zlhf.json —— 群内直接触发（直接编辑）
| 字段 | 说明 | 示例 |
|------|------|------|
| `gjc` | 关键词 → 回复内容映射 | `{"检测的内容": "收到后的回复"}` |
| `tp` | 回复的图片（URL 或本地路径） | `/path/to/image.png` |
| `sp` | 回复的视频（URL 或本地路径） | `/path/to/video.mp4` |
| `dt` | `true` 时图片正常发送，视频转为链接 | `true` / `false` |

### zlhf.json —— 可视化编辑
| 名称 | 说明 | 示例 |
|------|------|------|
| 关键词 | 触发词 | `#菜单` |
| 回复内容 | 对应的回复 | `当前指令有 #菜单` |
| 发送图片 | 图片 URL 或路径 | `https://xxx` |
| 发送视频 | 视频 URL 或路径 | `https://xxx` |
| 图片混合模式 | 勾选后图片正常发送，视频转为链接 | `不勾选` |
| 删除该规则 | 删除本条规则 | - |
| 添加规则 | 新增一条规则 | - |
| 保存全部 | 保存所有规则 | - |
| 刷新 | 重新渲染规则列表 | - |

### 🖼️ HTML 渲染功能（可选）
在 `zlhf.json` 中，回复内容以 `<!DOCTYPE html>` 开头时，插件会自动调用渲染服务将 HTML 转为图片发送
> 需自行部署 HTML 渲染服务（基于 Docker），并在插件配置中设置接口地址（详见下方「配置」章节）

### 📁 媒体文件存放建议

若视频、图片存放在本机，建议统一放在 `data/plugin_data/astrbot_plugin_qqAI/` 目录下，避免放在 `data/plugins/astrbot_plugin_qqAI/` 以防止被更新覆盖

> 💡 修改配置文件后，若未立即生效，请在 AstrBot WebUI 中重启插件或执行 `reload` 命令。

## ⚙️ 配置

在 AstrBot WebUI 中：`插件 → QQAI → 插件配置`

| 配置项 | 说明 | 示例 |
|--------|------|------|
| QQ群范围 | 仅处理这些群的消息（换行分割） | `123456789` |
| 意见反馈群 | 用户私信反馈发送到的群 | `423456789` |
| 进群验证群 | 开启进群验证的群（换行分割） | `123456789` |
| 验证超时（秒） | 超时未验证自动踢出 | `60` |
| 最大验证次数 | 错误次数上限 | `3` |
| HTML渲染接口 | HTML 转图片服务地址 | `http://localhost:8999/text2img/generate` |
