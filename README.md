# QQ消息处理功能插件

## ✨ 功能

- 自动回复
- 指令回复
- 多轮对话 / 分支对话
- 进群验证
- 退群通知
- 私信反馈意见
- 轻量的学习功能（非 AI，无需联网和 Token）
- 规则启用/禁用（可视化编辑）
- 关键词排除前缀 `>:://`
- 等等，详见更新日志

## 📦 安装方法

1. 在 AstrBot WebUI 的「插件市场」中，选择「从 Git 仓库安装」，输入以下地址：
   `https://github.com/HAGoStudio/astrbot_plugin_qqAI`
2. 重启 AstrBot

> 💡 首次启动时，插件会自动在 AstrBot 根目录下的 `data/plugin_data/astrbot_plugin_qqAI/` 目录下创建所需的配置文件，无需手动配置。

## 🚀 使用方法

配置文件位于 AstrBot 根目录下的 `data/plugin_data/astrbot_plugin_qqAI/` 中。

### zdhf.json —— @ 机器人触发（直接编辑）

| 字段 | 说明 | 示例 |
|------|------|------|
| `gjc` | 关键词 → 回复内容映射 | `{"检测的内容": "收到后的回复"}` |
| `sfjt` | 是否开启多轮对话 | `true` / `false` |
| `jtc` | 多轮对话配置，键为轮次，值为该轮选项数组 | `{"1": [{"选项1": "回复1"}]}` |

**支持的变量**：`{{当前时间}}`

**跳转指令**：

| 指令 | 说明 | 示例 |
|------|------|------|
| `回复内容:::数字` | 跳转到指定轮次（三位数字） | `好的，请选择:::002` |
| `回复内容:::end` | 结束多轮对话 | `好的，再见:::end` |

**HTML 渲染**：

回复内容以 `<!DOCTYPE html>` 开头时，自动渲染为图片发送（@回复、指令回复、多轮对话均支持）。

### zdhf.json —— 可视化编辑（重构版）

在 AstrBot WebUI 中：`插件 → QQAI → 打开插件UI界面 → 规则编辑器`

**界面布局**：

- **左侧**：规则列表，点击选中后可在右侧编辑
- **右侧**：选中规则的详细配置面板

**功能说明**：

| 功能 | 说明 |
|------|------|
| 添加规则 | 在列表末尾新增一条空白规则 |
| 删除规则 | 删除当前选中的规则 |
| 匹配关键词 | 设置触发该规则的关键词 |
| 启用 | 勾选后规则生效，取消勾选则临时禁用 |
| 回复内容 | 设置关键词匹配后的回复文本 |
| 多轮对话 | 勾选后开启多轮对话配置 |
| 添加轮次 | 新增一轮对话 |
| 删除轮次 | 删除当前轮次 |
| 添加选项 | 在当前轮次中添加一个选项（关键词 → 回复） |
| 删除选项 | 删除当前选项 |
| 保存全部 | 保存所有规则到 `zdhf.json` |
| 刷新规则 | 从配置文件重新加载规则 |
| 跳转至其他轮次或结束多轮对话 | 下拉框中选择数字即是跳转 选中end即是结束 |

**特殊规则**：
- 关键词以 `>:://` 开头的规则会被自动禁用，可用于临时停用某条规则而不删除

**支持的变量**：`{{当前时间}}`

**跳转指令**：

| 指令 | 说明 | 示例 |
|------|------|------|
| `回复内容:::数字` | 跳转到指定轮次（三位数字） | `好的，请选择:::002` |
| `回复内容:::end` | 结束多轮对话 | `好的，再见:::end` |

**HTML 渲染**：回复内容以 `<!DOCTYPE html>` 开头时，自动渲染为图片发送。

### zlhf.json —— 群内直接触发（直接编辑）

| 字段 | 说明 | 示例 |
|------|------|------|
| `gjc` | 关键词 → 回复内容映射 | `{"检测的内容": "收到后的回复"}` |
| `tp` | 回复的图片（URL 或本地路径） | `/path/to/image.png` |
| `sp` | 回复的视频（URL 或本地路径） | `/path/to/video.mp4` |
| `dt` | `true` 时图片正常发送，视频转为链接 | `true` / `false` |

**支持的变量**：`{{当前时间}}`

| 删除规则 | 删除当前选中的规则 |

| 启用 | 勾选后规则生效，取消勾选则临时禁用 |
| 回复内容 | 设置关键词匹配后的回复文本 |
| 回复图片 | 设置回复的图片（URL 或本地路径） |
| 回复视频 | 设置回复的视频（URL 或本地路径） |
| 图片混合模式 | 开启后只发送图片，视频以文字链接形式发送 |
| 保存全部 | 保存所有规则到 `zlhf.json` |

同样在 `插件 → QQAI → 打开插件UI界面 → 规则编辑器` 中，切换到「自动生成的回复」标签页。

### 🖼️ HTML 渲染功能（可选）

回复内容以 `<!DOCTYPE html>` 开头时，插件会自动调用渲染服务将 HTML 转为图片发送。

> 需自行部署 HTML 渲染服务（基于 Docker），并在插件配置中设置接口地址（详见下方「配置」章节）。

### 📁 媒体文件存放建议

若视频、图片存放在本机，建议统一放在 `data/plugin_data/astrbot_plugin_qqAI/` 目录下，避免放在 `data/plugins/astrbot_plugin_qqAI/` 以防止被更新覆盖。

> 💡 修改配置文件后，若未立即生效，请在 AstrBot WebUI 中重启插件或执行 `reload` 命令。

## ⚙️ 配置

在 AstrBot WebUI 中：`插件 → QQAI → 插件配置`

| 配置项 | 说明 | 示例 |
|--------|------|------|
| QQ群白名单 | 只会回复此范围内群聊的消息，换行分割可填写多个 | `123456789` |
| 意见反馈功能开关 | 开启后，用户通过私信发送的反馈内容将自动转发至指定的意见反馈接收群 | `true` / `false` |
| 意见反馈接收群 | 用户私信反馈意见发送到的群 | `423456789` |
| 进群验证开启群 | 发送进群验证的群，换行分割可填写多个 | `123456789` |
| 验证超时时间（秒） | 超时未验证自动踢出 | `60` |
| 最大验证次数 | 错误次数上限，超过自动踢出 | `3` |
| 验证通过后发送的欢迎 | 验证通过后发送的欢迎 | `验证通过，欢迎加入群聊！` |
| HTML渲染接口 | HTML 转图片的服务地址 | `http://localhost:8999/text2img/generate` |
| 学习功能开关 | 开启后自动学习新关键词（默认开启） | `true` / `false` |
